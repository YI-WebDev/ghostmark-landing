Overview

GhostMark が販売するもの

GhostMark は Chrome 向けのプライベートブックマーク保護拡張機能です。 販売対象は GhostMark Premium ライセンス で、 拡張機能内でライセンスキーを入力して有効化します。

Premium では、フォルダ別パスワード、緊急用デュレスモード、 暗号化バックアップの export / import、 保護タブを即時に閉じるパニックショートカットが解放されます。

How it works

3 段階で private link を隔離する

01

保存時に暗号化

URL とタイトルをローカルで暗号化して保存。通常一覧から生 URL を露出しません。

02

通常タブを即遮断

保護対象 URL を通常タブで開くと、GhostMark が検知してロック画面へ差し替えます。

03

認証後だけ別文脈へ

正しいパスワード入力後にのみ、シークレットウィンドウへ URL を引き渡します。

Use cases

「秘密の URL を URL のまま扱わない」ための UI

Premium を有効化すると、フォルダ単位の二段階保護や、 別データを見せるデュレスモードまで拡張できます。

Security posture

誇張しない。できることと、できないことを明記する。

GhostMark が守る範囲

  • ローカル保存時の URL / タイトル暗号化
  • 通常タブでの protected URL アクセス抑止
  • シークレットウィンドウへの限定的な再オープン
  • セッション終了時の解除情報クリア

GhostMark が保証しない範囲

  • DNS や OS / ルーター側の通信ログ秘匿
  • Chrome API の仕様を超えた完全な履歴不可視化
  • VPN や匿名化サービスの代替
  • クラウド同期型の秘密保管庫

FAQ

Stripe 審査や購入前確認で見られやすい点

GhostMark Premium で販売しているのは何ですか？

Chrome 拡張機能 GhostMark の Premium 機能を有効化するデジタルライセンスです。購入後にライセンスキーを発行し、拡張機能内でアクティベートします。

ブックマークデータはサーバーに送られますか？

GhostMark の保護対象ブックマークはローカル保存を前提にしており、保護データ自体を GhostMark のサーバーへ送る設計ではありません。

Premium を買わないと使えませんか？

いいえ。基本の暗号化保存、通常タブ遮断、認証後のシークレット再オープン、セッション管理は無料プランで利用できます。

どの機能が Premium ですか？

フォルダ別パスワード、パニックショートカット、緊急解除パスワードによるデュレスモード、暗号化バックアップの export / import が Premium 対象です。
