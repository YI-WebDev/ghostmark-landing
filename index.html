概要

ライセンスで解放されるもの

NinjaMark は Chrome 向けのプライベートブックマーク保護拡張機能です。販売対象は NinjaMark Premium ライセンス で、拡張機能内でライセンスキーを入力して有効化します。

Premium では、フォルダ別パスワード、緊急用デュレスモード、暗号化バックアップのエクスポート／インポート、保護タブを即時に閉じるパニックショートカットが解放されます。

セキュリティ

誇張しない。できることと、できないことを明記する。

NinjaMark が守る範囲

  • ローカル保存時の URL / タイトル暗号化
  • 通常タブでの保護 URL アクセス抑止（ブックマーク + ウォッチリスト）
  • 遮断時のブラウザ履歴自動削除 + トラッキングパラメータ除去
  • 認証後のみシークレットウィンドウで開く導線
  • セッション終了時の解除情報クリア

NinjaMark が保証しない範囲

  • フォルダ名など一部メタデータの完全秘匿
  • DNS や OS / ルーター側の通信ログ秘匿
  • Chrome API の仕様を超えた完全な履歴不可視化
  • VPN や匿名化サービスの代替

よくある質問

購入前によく確認されるポイント

NinjaMark Premium で販売しているのは何ですか？

Chrome 拡張機能 NinjaMark の Premium 機能を有効化するデジタルライセンスです。購入後にライセンスキーを発行し、拡張機能内でアクティベートします。

ブックマークデータはサーバーに送られますか？

NinjaMark の保護対象ブックマークはローカル保存を前提にしており、保護データ自体を NinjaMark のサーバーへ送る設計ではありません。

何が暗号化されますか？

ブックマークの URL とタイトルはローカルで暗号化されます。フォルダ名は一覧表示のため平文で保存されます。

Premium を買わないと使えませんか？

いいえ。基本の暗号化保存、通常タブ遮断、認証後のシークレット再オープン、セッション管理は無料プランで利用できます。

どの機能が Premium ですか？

フォルダ別パスワード、パニックショートカット、緊急解除パスワードによるデュレスモード、暗号化バックアップのエクスポート／インポートが Premium 対象です。

どんな権限や設定が必要ですか？

tabs 権限はオプションです。許可するとタブ監視による自動遮断と現在タブのクイック追加が有効になります。また、保護 URL をシークレットウィンドウで開くには Chrome の「シークレット モードでの実行を許可」も必要です。

ウォッチリストとは何ですか？

ブックマークとして保存せずにドメインだけ登録する機能です。ウォッチリストに追加したドメインへのアクセスは、ブックマーク保護と同じようにロック画面で遮断されます。

最後の呼びかけ

秘密の URL には、もう一つの扉が必要です。

NinjaMark Premium は、Chrome の普段の操作感を壊さずに、保護 URL だけ導線を切り替えるためのデジタルライセンスです。
